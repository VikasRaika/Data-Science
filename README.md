# Data Science & ML — models and applied projects

**A working notebook collection across the core ML algorithms and a set of applied, end-to-end data projects.**

![python](https://img.shields.io/badge/python-3.10%2B-blue)
![jupyter](https://img.shields.io/badge/Jupyter-notebooks-F37626?logo=jupyter&logoColor=white)

Two things in one place: clean implementations of the standard ML algorithms, and applied projects that take a real dataset from questions to answers.

## Applied projects
| Project | What it does |
|---|---|
| **Titanic Survival** | end-to-end classification: EDA, features, model, evaluation |
| **Stock Market Analysis** | pandas + visualisation of price, returns, risk and correlation |
| **USA Election — Polls & Donors** | data analysis of polling and campaign-donation datasets |
| **Handwritten Digits (Deep Learning)** | a neural network for digit classification |

## Algorithms & techniques
| Area | Notebooks |
|---|---|
| Regression | Linear Regression, Logistic Regression |
| Classification | Multi-class Classification, Naive Bayes (GaussianNB), Support Vector Machines, Random Forest |
| Unsupervised | K-Means clustering |
| Data wrangling | SQL in Python |

## Run it
```bash
git clone https://github.com/VikasRaika/Data-Science && cd Data-Science
pip install jupyterlab pandas numpy scikit-learn matplotlib seaborn
jupyter lab
```

## What it demonstrates
- Fluency across the core supervised, unsupervised and deep-learning models.
- Applied data-science: framing a question, wrangling data, and drawing conclusions.
- Comfort moving between pandas, scikit-learn, SQL and visualisation.
